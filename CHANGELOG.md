# Changelog

## 2.0.0

- Lightweight default NFS monitoring.
- Automatic NFS/NFSv4 mount discovery.
- Expected mount validation from `/etc/fstab`.
- Capacity monitoring and forecast.
- NFS server TCP/2049 availability and connection time.
- Optional detailed client performance monitoring with `{$NFS.PERFORMANCE}`.
- Optional functional NFSv3 RPC checks with `{$NFS.RPC.DEEP}`.
- Ten user-facing macros with sensible defaults.
